# Promise异步的终极武器
## 五、Event Loop 完整流程（六步法）



> 把前面散的知识收拢成一套解题流程，遇到任何输出题都按这六步走。



```text

步骤①：把所有代码当第一个宏任务，整体扫一遍

步骤②：同步代码从上到下执行，遇到异步任务就\"登记\"不执行

        - 遇到 setTimeout/setInterval → 注册到 Web API，回调等会儿进宏任务队列

        - 遇到 new Promise(fn) → fn 同步执行

        - 遇到 .then/.catch/.finally → 回调进微任务队列

        - 遇到 await → 暂停当前 async 函数，后续代码进微任务队列

步骤③：同步代码全部跑完 → 当前宏任务结束

步骤④：清空【所有】微任务（一个一个出列执行，新产生的微任务也当场清）

步骤⑤：检查是否需要 UI 渲染（浏览器，了解即可）

步骤⑥：从宏任务队列取下一个宏任务 → 回到步骤②

```



> **解题口诀**：先同步、后微任务、再宏任务；微任务一次清空，宏任务一次一个。
