# 自增主键推荐原因
## 七、为什么推荐自增主键？

B+树的叶子节点是按主键从小到大**一页一页往后排**的。

```text
用自增主键（id=1,2,3,4,5...）：
  每次新数据都在最后一页后面追加 → 新开一页就完事
  像在笔记本最后一页后面贴便利贴，很简单

用 UUID 主键（如 'a3f2c8b1-...'，无规律）：
  新数据的主键可能比已有的小 → 要插到中间 → 已有的页要分裂
  像在写满的笔记本第 52 页突然要插一页 → 需要把后面所有页往后挪
```

> **页分裂**很昂贵，涉及数据搬迁、磁盘随机写。自增主键能尽量避免。
