# Day 03：运算符与流程控制

> 🎯 **学习目标**：掌握 Python 全部运算符（7 大类），熟练编写分支和循环逻辑


## 1. 算术运算符

```python
a, b = 10, 3

print(a + b)     # 13  加法
print(a - b)     # 7   减法
print(a * b)     # 30  乘法
print(a / b)     # 3.3333333333333335  除法（结果始终是 float）
print(a // b)    # 3   整除（向下取整）
print(a % b)     # 1   取余（模运算）
print(a ** b)    # 1000  幂运算（10³）

# 整除的行为
print(10 // 3)    # 3
print(-10 // 3)   # -4  ← 注意！向下取整所以是 -4 不是 -3
print(10 // -3)   # -4

# 取余的妙用
print(17 % 5)    # 2  判断是否整除：17 ÷ 5 余 2
print(17 % 2)    # 1  判断奇偶：余 1 → 奇数
print(18 % 2)    # 0  余 0 → 偶数

# 幂运算
print(2 ** 10)   # 1024
print(16 ** 0.5)  # 4.0  （开平方）
```

> [!tip] 取余的常见应用
> - 判断奇偶：`n % 2`
> - 循环索引：`index % length`
> - 提取个位：`n % 10`

## 2. 赋值运算符

```python
# 基本赋值
x = 10

# 复合赋值
x += 5    # x = x + 5
x -= 3    # x = x - 3
x *= 2    # x = x * 2
x /= 4    # x = x / 4
x //= 2   # x = x // 2
x %= 3    # x = x % 3
x **= 2   # x = x ** 2

# 多重赋值（Python 特色）
a, b, c = 1, 2, 3     # 同时给多个变量赋值

# 交换变量（一行搞定，不需要临时变量！）
a, b = b, a
print(a, b)  # 2, 1

# 链式赋值
x = y = z = 100       # 三个变量都赋值为 100
```

## 3. 比较（关系）运算符

```python
print(10 == 10)    # True   等于
print(10 != 5)     # True   不等于
print(10 > 5)      # True   大于
print(10 < 5)      # False  小于
print(10 >= 10)    # True   大于等于
print(10 <= 5)     # False  小于等于

# 链式比较（Python 特色！）
age = 25
print(18 <= age <= 60)   # True ← 等价于 18 <= age and age <= 60
# 在 C/Java 中必须写成 age >= 18 && age <= 60

# 字符串也可以比较（按字典序）
print("abc" < "abd")   # True
print("A" < "a")       # True（大写 ASCII 值 < 小写）
```

## 4. 逻辑运算符

```python
# and：两边都为 True 才返回 True
print(True and True)    # True
print(True and False)   # False
print(False and True)   # False
print(False and False)  # False

# or：至少一边为 True 就返回 True
print(True or False)    # True
print(False or False)   # False

# not：取反
print(not True)         # False
print(not False)        # True
```

### 短路运算（重要！⭐）

```python
# and 短路：左边为 False 时，右边不执行
def check():
    print("check 被调用了")
    return True

print(False and check())  # 只输出 False，check() 没有被调用！

# or 短路：左边为 True 时，右边不执行
print(True or check())    # 只输出 True，check() 没有被调用！

# 利用短路做默认值
name = ""
display_name = name or "匿名用户"   # "匿名用户"
# 原理：空字符串是 False，所以 or 返回右边
```

## 5. 位运算符

位运算直接操作二进制位，效率极高：

```python
a, b = 0b1100, 0b1010  # a=12, b=10

# & 按位与：两位都为 1 才为 1
print(bin(a & b))  # 0b1000 = 8
# 1100 & 1010 = 1000 (按位与)

# | 按位或：至少一位为 1 就为 1
print(bin(a | b))  # 0b1110 = 14

# ^ 按位异或：两位不同为 1
print(bin(a ^ b))  # 0b0110 = 6

# ~ 按位取反
print(~a)  # -13（补码机制）

# << 左移：二进制位向左移，右边补 0（每移一位 = ×2）
print(5 << 1)  # 10  = 5×2
print(5 << 2)  # 20  = 5×4
print(5 << 3)  # 40  = 5×8
# 5 = 0b0101 → 左移2位 → 0b010100 = 20

# >> 右移：二进制位向右移，左边补符号位（每移一位 = ÷2）
print(16 >> 1)  # 8   = 16÷2
print(16 >> 2)  # 4   = 16÷4
print(16 >> 3)  # 2   = 16÷8
```

## 6. 成员运算符

```python
# in：判断元素是否在容器中
print("a" in "Python")           # False
print("th" in "Python")          # True
print(3 in [1, 2, 3, 4])        # True
print("name" in {"name": "张三"})  # True（判断 key）

# not in：不在
print(5 not in [1, 2, 3])       # True
```

## 7. 身份运算符

```python
# is：判断是否指向同一个对象（比较内存地址）
# ==：判断值是否相等

a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)  # True  （值相等）
print(a is b)  # False （不同对象，不同内存地址）
print(a is c)  # True  （同一对象）

# Python 的整数缓存（-5 到 256）
x = 256
y = 256
print(x is y)  # True  （Python 缓存了小整数）

x = 257
y = 257
print(x is y)  # 可能是 False（超出缓存范围，创建了不同对象）
```

> [!important] `==` vs `is`
> `==` 比较**值** | `is` 比较**是否是同一个对象**
> 日常开发里 99% 的情况用 `==`，`is` 主要用于判断 `is None`


## 8. Python 编码规范

正式开发前，先了解 Python 社区统一的代码风格——**PEP 8**：

```python
# 缩进：用 4 个空格（不要混用 Tab！）
if True:
    print("缩进 4 个空格")      # ✅
    # print("Tab 缩进")          # ❌

# 空格：运算符两边各一个空格
x = 1 + 2                       # ✅
x=1+2                           # ❌

# 逗号后面加空格
items = [1, 2, 3]               # ✅
items = [1,2,3]                 # ❌

# 函数参数逗号后加空格
def func(a, b, c):              # ✅
    pass

# 行长度：不超过 79 字符（或 120 字符，团队约定）
# 过长的行可以用括号换行
result = (long_function_name(arg1, arg2, arg3)
          + another_function(arg4))

# 空行：函数间空两行，类方法间空一行

# 导入：每个导入独占一行
import os                       # ✅
import sys                      # ✅
import os, sys                  # ❌
```

> [!tip] 善用工具
> 以后学了 ruff/black 等格式化工具，可以**一键自动格式化**代码，不需要手动调整。


## 9. 单分支 if

```python
# 基本语法
age = 18
if age >= 18:
    print("已成年")
    print("可以进入网吧")
# 注意：if 语句块通过缩进区分！

# if 后面的条件可以是任意表达式
score = 85
if score >= 60:
    print(f"成绩 {score} 及格")

# 利用"非零即真"的特性
count = 5
if count:          # count != 0
    print(f"还有 {count} 个")
```

## 10. 双分支 if-else

```python
age = 16
if age >= 18:
    print("已成年")
else:
    print("未成年")

# 实际应用：登录验证
password = input("请输入密码：")
if password == "123456":
    print("✅ 登录成功")
else:
    print("❌ 密码错误")
```

## 11. 多分支 if-elif-else

```python
score = 85

if score >= 90:
    grade = "优秀"
elif score >= 80:
    grade = "良好"
elif score >= 70:
    grade = "中等"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"

print(f"成绩等级：{grade}")

# ⚠️ elif 是"排他"的，上方条件满足后，不再判断下方
# 因此条件的顺序很重要！
```

## 12. 嵌套分支

age = 25

## 13. match-case 语句（Python 3.10+，⭐新特性）

传统 if-elif 判断多个值比较啰嗦，match-case 更优雅：

```python
# 传统写法
status_code = 404
if status_code == 200:
    msg = "成功"
elif status_code == 301 or status_code == 302:
    msg = "重定向"
elif status_code == 404:
    msg = "未找到"
elif status_code == 500:
    msg = "服务器错误"
else:
    msg = "未知"

# match-case 写法（Python 3.10+）
status_code = 404
match status_code:
    case 200:
        msg = "成功"
    case 301 | 302:               # | 表示"或"
        msg = "重定向"
    case 404:
        msg = "未找到"
    case 500:
        msg = "服务器错误"
    case _:                       # _ 表示默认（类似 else）
        msg = "未知"

print(msg)  # "未找到"

# match 可以做更复杂的模式匹配
point = (0, 5)
match point:
    case (0, 0):
        print("原点")
    case (0, y):
        print(f"在 Y 轴上，y={y}")    # 匹配这个！
    case (x, 0):
        print(f"在 X 轴上")
    case (x, y):
        print(f"坐标 ({x}, {y})")
# 输出："在 Y 轴上，y=5"
```

> [!tip] 什么时候用 match-case
> - 多分支判断且条件都是等值比较
> - 需要解构数据（如坐标、元组）
> - Python 3.10 以下版本不支持，注意兼容性

## 14. 三目运算符

```python
# 语法：结果1 if 条件 else 结果2
age = 20
status = "成年" if age >= 18 else "未成年"
print(status)  # "成年"

# 等价于：
if age >= 18:
    status = "成年"
else:
    status = "未成年"

# 可以嵌套（但不推荐，可读性太差）
score = 85
result = "优秀" if score >= 90 else ("良好" if score >= 80 else "一般")
```

## 15. while 循环

### 15.1 基本语法

```python
# 打印 0 到 4
count = 0
while count < 5:
    print(f"第 {count} 次循环")
    count += 1
# 输出：0, 1, 2, 3, 4
```

### 15.2 三种关键条件

```python
# ⚠️ 无限循环必须有退出条件！
while True:
    user_input = input("输入 'quit' 退出：")
    if user_input == "quit":
        break          # 跳出循环
```

### 15.3 while-else

```python
# else 在循环正常结束（非 break）时执行
count = 0
while count < 3:
    print(count)
    count += 1
else:
    print("循环正常结束")    # ✅ 会执行

# 如果被 break 中断，else 不执行
count = 0
while count < 10:
    if count == 3:
        print("提前退出！")
        break
    count += 1
else:
    print("循环正常结束")    # ❌ 不会执行（被 break 了）
```

### 15.4 实际应用

```python
# 数字猜谜游戏
import random
answer = random.randint(1, 100)
guess = None
attempts = 0

while guess != answer:
    guess = int(input("猜一个 1-100 的数："))
    attempts += 1
    if guess > answer:
        print("大了")
    elif guess < answer:
        print("小了")

print(f"🎉 恭喜！答案就是 {answer}，你用了 {attempts} 次")
```

## 常见坑点

### 1. 整除向下取整陷阱
```python
print(10 // 3)    # 3
print(-10 // 3)   # -4 ← 不是 -3！
print(10 // -3)   # -4
```
- **原理**：`//` 是向下取整（floor division），不是截断
- **类比**：数轴上向左取整，-3.33 向左是 -4
- **解决**：需要截断用 `int(a / b)`

### 2. 浮点数除法精度
```python
print(0.1 + 0.2)        # 0.30000000000000004
print(0.1 + 0.2 == 0.3) # False
```
- **原因**：0.1 和 0.2 在二进制中是无限循环小数
- **解决**：使用 `decimal.Decimal('0.1')` 或整数运算

### 3. 链式比较的短路特性
```python
x = 5
print(1 < x < 10)   # True
print(1 < x > 10)   # False ← x>10 为 False，但不会报错
print(1 < x < 3)    # False ← x<3 为 False
```
- **原理**：链式比较相当于 `1 < x and x < 10`，短路求值

### 4. `is` vs `==` 的混淆
```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True（值相等）
print(a is b)   # False（不是同一个对象）
print(a is a)   # True（同一个对象）
```
- **规则**：`==` 比较值，`is` 比较内存地址（id）
- **坑点**：小整数缓存（-5~256）可能导致 `is` 返回 True

### 5. 逻辑运算符的返回值
```python
print(1 and 2)    # 2 ← 不是 True！
print(0 or 5)     # 5 ← 不是 True！
print(1 or 2)     # 1 ← 不是 True！
```
- **原理**：`and` 返回第一个假值或最后一个真值；`or` 返回第一个真值或最后一个假值
- **记忆**：`x and y` → 如果 x 为假返回 x，否则返回 y

### 6. 成员运算符的效率
```python
# 列表查找 O(n)
print(3 in [1, 2, 3, 4, 5])  # True

# 集合查找 O(1)
print(3 in {1, 2, 3, 4, 5})  # True

# 字符串查找 O(n)
print('a' in 'abc')           # True
```
- **优化**：频繁查找用集合（set）而非列表（list）
